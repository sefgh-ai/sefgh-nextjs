# 🚀 Quick Start - Professional Code Display & Canvas

## In 30 Seconds

**What you got:**
1. ✨ ChatGPT-style code blocks with syntax highlighting
2. 🎨 Side-by-side Canvas editor (like Claude Artifacts)
3. 📋 One-click copy & download
4. 🎯 16+ programming languages supported

---

## Try It Now (3 Steps)

### Step 1: Run your app
```bash
npm run dev
```

### Step 2: Go to chat
```
http://localhost:3000/chat
```

### Step 3: Ask AI for code
```
"Write a hello world function in JavaScript"
```

**You'll see:**
- Professional code block with colors
- Copy button (📋)
- Open in Canvas button (⛶)
- Language label

---

## Key Features

### 🎨 Code Blocks
```
┌─────────────────────────┐
│ 🔴🟡🟢  python    📋 ⛶ │  ← Click buttons!
├─────────────────────────┤
│ def hello():            │  ← Colored syntax
│   print("Hello")        │
└─────────────────────────┘
```

### 🖥️ Canvas
- Click ⛶ → Opens on right side (desktop) or full screen (mobile)
- Edit code with line numbers
- Preview with syntax highlighting
- Download with auto file extension

---

## Quick Actions

| Action | How |
|--------|-----|
| Copy code | Hover block → Click 📋 |
| Open in canvas | Hover block → Click ⛶ |
| Close canvas | Click ✕ in canvas header |
| Download code | Open canvas → Click ⬇️ |
| Change language | Open canvas → Select from dropdown |
